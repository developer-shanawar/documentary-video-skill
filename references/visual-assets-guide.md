# Visual Assets Guide — Icons, Templates, Images, How Videos Run

## Icons — how to use them

- Use simple, flat 2D icons that match the host style: deep teal + warm amber, thick outline, no photorealistic detail.
- One icon = one idea. A drain icon for drainage, a brick icon for bricks, a river icon for river shift. Do not use 5 icons for one idea.
- Icons go on diagrams, maps, and lists — never over a face, never over the main text.
- Size: an icon must be readable on a phone. If you need to zoom to read it, it is too small.
- Sources: use icons you made, or icons from a library with a clear licence for commercial use. Note the source in your working notes. Do not take an icon from another creator's video.

## Template images — how to use them

- A template image is a reusable background / frame, not a finished thumbnail. Examples in this skill: the dark-teal framed border for diagrams, the timeline badge lower-left, the date pill top-right, the name card bottom-left.
- Keep templates the same in every video: same border, same pill, same card, same colours. That is what makes the channel look like one channel.
- Never bake text into a template image. Text is added in edit, per beat, then removed.
- If a template image has a fake watermark or garbled text baked in, reject it and regenerate clean.

## Real images vs 2D animation — how videos run

- First 10 seconds: animation only, never a still real photo.
- After that: mix animation with real images, but only with visible zoom/pan motion. A real image with no motion is a frozen still — never export that.
- Real images: public-domain / freely licensed only, whole image in frame, only zoom/crop, real colours unchanged, labelled as real.
- Present-day photos: label them "real present-day view", never present them as ancient footage.
- Reconstructions: label them as reconstructions, never as real photos.
- Old topics: old houses, old drains, old tools, old streets. No modern buildings, clothes, or objects in an old scene.

## How a video runs, beat by beat

1. Beat 1 (0:00–0:10): animation, biggest visual first, hook question, date pill if needed.
2. Beats 2–4: evidence — diagram, map, real image, document — one per beat, no repeats, camera angle changes every 8–10 seconds.
3. Beats 5–6: payoff or question, host in foreground, full-screen cutaway for the payoff visual.
4. Every beat: something moves, voice matches visual, at most one small text.
5. End: open question + personal sign-off, no hard subscribe graphic.

## Checklist before export

- [ ] Icons match the style and are readable on a phone
- [ ] Templates are the same as last video
- [ ] Real images labelled real, reconstructions labelled reconstruction
- [ ] First 10 seconds animation, every segment moving
- [ ] Text system correct, host silent hands down
