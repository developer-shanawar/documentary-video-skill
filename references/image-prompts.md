# Image Prompts — Documentary Video Skill

One visual per narration beat. NO repeats. Every prompt must name the style, the subject, the motion, and what must NOT be in the frame.

## Base style (add to every animation prompt)

> Clean 2D documentary animation, same style as a sticky-man explorer host: large round white head, dot eyes, small smile, khaki cap, teal vest, brown backpack, khaki cargo pants, brown boots. Deep teal and warm amber palette, warm studio light, flat colours, no photorealism, no realistic people, no text, no watermark, no logo.

Add "no text in the image" to every prompt unless the diagram itself needs a label — and then name the exact label.

## Host scenes

- Hook: "2D animation, sticky-man explorer host standing in his warm room looking up at a large board with a question mark, curious expression, subtle walking motion, camera slowly pushes in, [base style]."
- Document explainer: "2D animation, sticky-man explorer host beside a board showing [document/diagram], host standing still with subtle head turn, camera medium close-up, [base style]."
- History viewer: "2D animation, sticky-man explorer host in the foreground watching a 2D animated scene of [old city / event] behind him, host is NOT inside the historical scene, camera over-the-shoulder, [base style]."
- Map/measurement: "2D animation, top-down old map of [place], a dotted route animates across it, a small scale bar appears, camera slow pan, [base style]."

## Diagrams and measurements

- "2D animated diagram of [subject], cross-section view, main part highlighted with a warm amber arrow, slight slow zoom from 100% to 108%, dark teal framed border, whole diagram stays in frame, clean labels only: [list the exact labels]."
- Show one number in 3 pictures: the same number as (1) a diagram, (2) a map, (3) a real image — with the same value in all three.

## Old-world scenes

- "2D animation of an old [city / street / house] in [period], old mud-brick houses, old drainage channel with water flowing under the houses, people in simple old clothes walking, birds moving, camera slow pan left to right, everything looks old, no modern buildings, no modern clothes, [base style]."

## Real images (not generated)

Do not generate a fake "real photo". Search for a real one:

- Use public-domain / freely licensed sources only (for example Wikimedia Commons, museum open collections, government archives).
- Check the licence before use. If the licence is unclear, do not use it.
- Use the whole image in frame, only zoom/crop, real colours unchanged, slight zoom/pan motion so it is not a frozen still.
- On screen, label it as real. In working notes, keep the source link and licence.
- Present-day ruins/river photos: label "aaj ki tasveer" / "present day" in the voiceover or on screen. Never present them as ancient footage.

## Prompts to avoid

- "Realistic photo of ancient workers" — wrong style, wrong claim.
- "Cinematic photorealistic scene" — breaks the 2D host style.
- A prompt with no motion note — every clip must say what moves.
- A prompt that asks for text in the image — text is added later by the locked pill/card system, not baked into the clip.
