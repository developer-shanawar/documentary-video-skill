# YouTube Upload Checklist — Documentary Video Skill

Honest limit first: this skill does NOT upload to YouTube by itself, and it does NOT log into your channel. Upload is manual in YouTube Studio. This checklist is what to do there, step by step.

## Before upload

- [ ] Final video watched fully once, with sound: no frozen segment, no silent gap over 1–2 seconds, every visual matches its voice line
- [ ] Text system checked: date pill top-right, name card bottom-left for 2 seconds only, no top bar, no solid box
- [ ] Facts checked once more: dates, numbers, names — see `fact-check-checklist.md`
- [ ] Thumbnail made: 1280x720, 3–4 words maximum, readable on a phone, no misleading claim
- [ ] Title ready: a question or a counter-claim, not a summary. Write 3 options, pick 1.
- [ ] Description ready: first 2 lines say the angle, then timestamps, then keywords/hashtags
- [ ] Tags ready: within YouTube's 500-character limit

## In YouTube Studio

- [ ] Video file uploaded as Unlisted first, checked, then set to Public
- [ ] Title pasted, thumbnail uploaded
- [ ] Description pasted with timestamps
- [ ] Tags pasted, language set, playlist chosen
- [ ] End screen added: next video / subscribe, no hard subscribe graphic inside the video itself
- [ ] Cards added only where they help, not on every beat
- [ ] Visibility, audience, and licence settings checked

## First 48 hours — check, do not panic

- [ ] Click-through rate and average view duration noted, no view/virality guarantee
- [ ] Comments read: which question did viewers actually ask? Note it for the next video
- [ ] If retention drops at one beat, note the exact timecode and what visual was on screen

## What this skill gives you for upload

- Title formulas and 3 title options per video
- Description template with timestamps, keywords, hashtags
- Tags within the 500-character limit
- Thumbnail text (3–4 words) and thumbnail image prompt
- This checklist, so nothing is missed

What it does not give: an automatic upload, a live view count, or a promise of views.
