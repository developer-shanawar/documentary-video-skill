# Style Guide — Documentary Video Skill

The full locked rules. `SKILL.md` is the summary; this file is the detail. If the two ever disagree, follow this file and update `SKILL.md`.

## 1. Host

- Sticky-man explorer v2. Large round white head. Dot eyes, dot nose, smile + eyebrows only. NO ears, NO hair.
- Outfit (same every video): khaki cap, teal vest, brown backpack, khaki cargo pants, brown boots.
- Setting: warm studio / his own room, walks to a board and explains on the board. Colours: deep teal + warm amber. Clean 2D style.
- The host is NOT a real person and must not be drawn as one. Do not swap in a human presenter design.
- Host uses, in order: Hook Question → Document Explainer → History Viewer → Map/Measurement/Flow split → Payoff/Lesson.
- History Viewer: host in the foreground looking at history, NOT inserted into the historical scene.
- Host is silent on screen: mouth closed, no talking, no lip sync. Narration is background voiceover only.
- Movement: subtle walking, head turn, gentle body motion. Hands stay DOWN at all times — no waving, no pointing, no gesturing.

## 2. Visuals

- 2D animation matching the host's cartoon style. This is the default for every scene, including village/people/crop scenes.
- Do NOT use realistic worker-type footage or animation for people scenes.
- First 10 seconds of any video must be ANIMATION.
- After that, real images/video may be mixed in, but only with visible zoom/pan motion, and only where they add value. Otherwise use moving animation.
- Real images: public-domain / freely licensed only. Label them as real. Never label a present-day photo as ancient footage. Never label a reconstruction as a real photo.
- Old topics must look OLD: old houses, old drains with water under old houses, old tools, old streets. No modern buildings, modern clothes, or modern objects in an old scene.
- Every 10-second segment must have continuous MOTION: walking, flowing water, moving people, camera movement. No frozen/stuck segment.
- No element fully frozen/static for more than 4–5 seconds.
- Camera: change angle every 8–10 seconds — Wide → Medium close-up → Over-the-shoulder. Subtle slow digital zoom-in/pan on important points. Full-screen cutaways / B-roll for ruins, maps, tools, diagrams instead of the character standing still.
- Diagrams: slight zoom 100% to ~108% inside a framed dark-teal border. Whole image stays in frame. Main part highlighted with arrows. Only zoom/crop, real colours unchanged.
- Timeline year: small lower-left badge, about 1/6 of the frame, clear in the first 3 seconds and spoken in the voiceover.

## 3. On-screen text (locked)

- DATE: small, TOP-RIGHT corner, inside a small ROUNDED PILL (dark rounded bar, animated fade), stays for the beat.
- NAME: small ROUNDED CARD, BOTTOM-LEFT corner (x=40, y=H-90), only 2 seconds (t=1–3s), then gone.
- Date and name are NEVER in the same row. The name card must never cover the main visual (it used to sit in the middle and covered the asteroid visual — that is why it moved to the bottom-left).
- No top bar. No solid/box behind any text. No generic titles: THE QUESTION, THE FIRST NAME, THE NAME, THE NUMBER, WHO SURVIVED, THE OPEN QUESTION, REMEMBER THIS FACT, YOUR TURN — all removed.
- One small text per beat. White with black outline. Fade in/out ~0.8s. Different position each beat where the system allows it.
- No "Part 1 / Part 2" labels on screen. Segments flow into each other and combine at the end.

## 4. Audio

- Voiceover ONLY by default. Voice: Young 3, speed 100. Language: Roman Urdu + balanced technical English words.
- NO music, NO SFX unless the user explicitly asks. If BGM or per-reveal SFX are added, licence-check them before monetised/commercial use. Do not assume a sound from a free-sound site is free for commercial use.
- Openings: relaxed, curious questions. NOT shouting hooks.
- No silent gaps. Narration fills each segment. Trim dead air longer than 1–2 seconds between voiceover lines.
- No part should end with an "agle part mein samjhenge / agle minute mein dekhenge" promise in every part. End a beat on a question only.

## 5. Story and honesty

- Structure: full-stack hook + evidence + diagram + real image + payoff.
- Hook: counter-claim then a question in the first 15 seconds.
- Science/evidence first, then an explicit pivot to text/interpretation if any.
- Fact, disputed point, theory, and personal interpretation are separate. Interpretation is labelled interpretation, never presented as proof. A text is never claimed to name something it does not name.
- One number repeated in 3 pictures where it helps: for example a measurement as a diagram, a map, and a real image.
- Word-to-picture matching at all times.
- Ending: open question + personal sign-off. No hard subscribe graphic.
- Graphs show only one realistic main concept, with no extra labels.
