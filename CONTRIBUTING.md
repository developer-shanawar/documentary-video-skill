# Contributing

Thanks for helping improve this skill.

## How to contribute

1. Fork the repo and create a branch for your change.
2. Keep the locked style rules intact — if you change a rule in `SKILL.md`, update `references/style-guide.md` to match.
3. Do not add copied scripts, footage, or text from other creators. Everything here must be original or properly licensed.
4. Test your change: run the sample prompt in `INSTALL.md` and run `scripts/make_storyboard.py` on `examples/sample-beats.json`.
5. Open a pull request with a short description of what changed and why.

## What we welcome

- Clearer wording, better examples, and new templates
- More fact-check sources and prompt templates
- Bug fixes in the script

## What we do not accept

- Copied content from other creators
- Invented facts, numbers, or quotes
- Changes that break the locked text system, host rules, or scene-voice matching
