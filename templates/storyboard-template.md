## Rules for every row

- Visual: 2D animation matching the host style, unless the row is a labelled real image with zoom/pan motion.
- Motion: name what moves. Never write "static" or leave it blank.
- On-screen text: date pill (top-right) and/or name card (bottom-left, 2 seconds only). Never both in the same row position, never a top bar, never a solid box.
- Host: silent, mouth closed, hands down, no pointing. Subtle walking/head-turn only.
